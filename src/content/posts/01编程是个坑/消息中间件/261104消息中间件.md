| 对比项  | Kafka               | RabbitMQ                    |
| ---- | ------------------- | --------------------------- |
| 核心模型 | 分布式提交日志、事件流         | 消息代理、队列                     |
| 吞吐量  | 很高，适合海量数据           | 较高，适合常规业务消息                 |
| 消息消费 | 消费者可按偏移量重复读取        | 消息通常被确认后从队列移除               |
| 路由能力 | 相对简单，主要通过 Topic 和分区 | 强，支持 Exchange、Routing Key 等 |
| 典型场景 | 日志、埋点、流式处理、数据同步     | 订单异步处理、任务队列、服务解耦            |
