通读全文，检索出来发现有4处自定义AOP

项目自定义的 AOP 共 4 处：

| 注解                | 切面                                                                                   | 类型                                                                          | 作用                                |
| ----------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------- | --------------------------------- |
| `@Log`            | `LogAspect`（ruoyi-common-log/.../aspect/LogAspect.java:65）                           | `@Around`                                                                   | 记录操作日志，发布 `OperLogEvent`          |
| `@RepeatSubmit`   | `RepeatSubmitAspect`（ruoyi-common-redis/.../aspectj/RepeatSubmitAspect.java:49）      | `@Before` / `@AfterReturning` / `@AfterThrowing`                            | 基于 Redis 的防重复提交                   |
| `@RateLimiter`    | `RateLimiterAspect`（ruoyi-common-redis/.../aspectj/RateLimiterAspect.java:59）        | `@Before`                                                                   | Redisson 分布式限流，支持 SpEL            |
| `@DataPermission` | `DataPermissionPointcutAdvisor` + Pointcut + Advice（ruoyi-common-mybatis/.../aspect） | 编程式 Spring AOP（`MethodInterceptor`，在 `MybatisPlusConfiguration.java:76` 注册） | 数据权限，兼容 MyBatis Mapper 的 JDK 动态代理 |

非自定义（框架/第三方库提供）的 AOP 主要有 6 类：

| 注解                                         | 来源                 | 使用量         | 说明                                                                                                         |
| ------------------------------------------ | ------------------ | ----------- | ---------------------------------------------------------------------------------------------------------- |
| `@Transactional`                           | Spring TX          | 41          | 声明式事务，`@EnableTransactionManagement(proxyTargetClass = true)`（MybatisPlusConfiguration.java:40）            |
| `@Cacheable` / `@CacheEvict` / `@CachePut` | Spring Cache       | 15 / 17 / 9 | `@EnableCaching`（CacheConfiguration.java:19），底层 Redisson CacheManager                                      |
| `@Async`                                   | Spring Async       | 3           | `@EnableAsync(proxyTargetClass = true)`（ApplicationConfig.java:14）                                         |
| `@Lock4j`                                  | Lock4j             | 8           | 分布式锁，由 Lock4j 自带的 AOP 拦截器实现（如 SysLoginService.java:70）                                                     |
| `@DS` / `@DSTransactional`                 | dynamic-datasource | 12          | 多数据源切换/事务，`DynamicDataSourceAnnotationAdvisor` 实现                                                          |
| `@Validated`                               | Spring Validation  | 82          | 类/方法级方法参数校验走 `MethodValidationPostProcessor`（AOP）；但绝大多数用在 Controller 的 `@RequestBody` 上，那是 MVC 参数校验，不算 AOP |
