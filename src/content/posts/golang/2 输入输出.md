# 2.输入输出

## 输出

```go
func main() {
	fmt.Println("hdas")
	fmt.Print("不换行")
	fmt.Println("-----")
	// 格式化输出 %s:字符串；\n:换行；%d:数字；%f:浮点数
	fmt.Printf("%s 哇，你好美！\n", "宝贝")
	fmt.Printf("%d \n", 123)         // 123
	fmt.Printf("%f \n", 123.46423)   // 123.464230
	fmt.Printf("%.3f \n", 123.46483) // 123.465
	fmt.Println("----")

	// 打印值的类型
	fmt.Printf("%T %T %T \n", "Hello", 20, 3.2312) // string int float64
	// 任意类型，打印值本身
	fmt.Printf("%v \n", "Hello")
	fmt.Printf("%v \n", 123.245)
	fmt.Printf("%v \n", 123) // 123

	//  %#v:将完整的字符串输出出来
	fmt.Printf("%#v \n", "123") // "123"
	fmt.Printf("%#v \n", "")    // ""

	// %#v:用于复杂的数据结构
	type User struct {
		Name string
		Age  int
	}
	u := User{"Alice", 30}
	fmt.Printf("%v  \n", u)  // 输出: {Alice 30}
	fmt.Printf("%#v  \n", u) // 输出: main.User{Name:"Alice", Age:30}
	fmt.Printf("%T  \n", u)
}
```

## 输入

如果输入非int类型，如“abc”，无法转成int类型，则是会出现问题的

```go
fmt.Print("请输入年龄：")
var age int
fmt.Scan(&age)
fmt.Println(age) // 如果输入非数值，则输出0
```
