# AI Agent 记忆机制详解

在构建智能体（AI Agent）时，记忆机制是其具备任务连续性、上下文感知和长程规划能力的核心基石。参考认知心理学模型与现代 Agent 架构设计，记忆系统通常划分为以下四层：

---

## 1. 感知记忆 (Sensory Memory)

- **核心定位**：存续时间最短的记忆层，对应 Agent 对瞬时外界刺激的直接感知。
- **主要内容**：单轮对话中用户输入的即时原始信息（Prompt、上传的单张图片、临时附件文档、语音切片等）。
- **生命周期与回收**：
  - **单次生效（Ephemeral）**：仅在当前推理调用（Inference Call）中有效。
  - **用完即弃**：一旦本轮推理完成，原始感知输入便不会自动保留，除非被显式写入上下文或持久化存储。

---

## 2. 短期记忆 / 工作记忆 (Short-Term / Working Memory)

- **核心定位**：Agent 执行具体任务过程中的“工作台”，即大语言模型的**上下文窗口（Context Window）**。
- **主要内容**：
  - 会话历史消息（`messages` 列表，包含 `system`、`user`、`assistant`、`tool`）。
  - 工具调用的入参、执行结果及任务中间状态。
  - Agent 自我反思（ReAct/Chain-of-Thought）过程中的思考推论链路。
- **管理与回收策略**：
  - **任务闭环清空**：当前任务完全达成后，清空对应的临时会话状态与中间推理，重置上下文。
  - **滑动窗口截断（Sliding Window Truncation）**：当上下文长度逼近模型 Token 上限时，主动裁剪或丢弃最早的历史消息，腾出空间容纳新内容。
  - **会话压缩 / 滚动总结（Summarization）**：对较早的多轮交互进行摘要提炼，以紧凑的摘要替代冗长的原始对话，兼顾长程上下文与 Token 消耗。

---

## 3. 长期记忆 (Long-Term Memory)

- **核心定位**：支持**跨会话、跨任务**的经验与知识沉淀，实现历史经验的复用与自我进化。
- **存储载体**：外部持久化存储介质，主要包括：
  - **向量数据库**（如 Milvus, Qdrant, Chroma 等）：用于语义搜索与多模态匹配。
  - **关系型与文档型数据库**（如 PostgreSQL/pgvector, MongoDB）：存储完整的历史交互归档与元数据。
- **机制与应用**：
  - 通过 **RAG（检索增强生成）** 或混合检索（Hybrid Search: 向量语义检索 + BM25 关键词匹配）技术，在 Agent 处理新任务时按需召回相关历史，避免无限堆积到上下文窗口中。

---

## 4. 实体记忆 (Entity / Semantic Memory)

- **核心定位**：从原始交互中提炼出高价值事实与认知资产的精炼层。
- **主要内容**：
  - **用户画像与个性化偏好**：如用户技术栈、交互风格倾向、预算限制等。
  - **实体事实与关系网**：从自由文本中抽取的客体、属性及其关联（如“项目A的负责人是张三”）。
- **技术实现**：
  - 通过实体识别（NER）或 LLM 结构化提取（Function Calling / Structured Outputs）清洗非结构化文本。
  - 转换为键值对（Key-Value Store）、图数据库（Knowledge Graph）或轻量配置存储。
- **特点与优势**：
  - **信息密度极高**：去除了自然语言的口语与冗余表达。
  - **即时注入**：可作为长期偏好，轻量注入到 System Prompt 或作为检索过滤器使用。

---

## 记忆分层对比总结

| 记忆类型 | 认知类比 | 物理载体 | 留存周期 | 典型内容 | 回收/驱逐策略 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **感知记忆** | 瞬时感官知觉 | 本轮请求 Buffer | 单次请求 | 原始图片、单次语音、临时文档 | 推理结束后自动释放 |
| **短期记忆** | 工作记忆 / 短期暂存 | 模型 Context Window | 当前任务/单会话内 | 消息历史、工具返回、推理中间态 | 任务完成重置 / 截断 / 滚动总结 |
| **长期记忆** | 场景记忆 / 经验库 | 向量库、SQL、NoSQL | 长期/跨会话 | 历史问答归档、任务案例库、外部文档 | 定期清理、基于访问频次/热度衰减 |
| **实体记忆** | 语义记忆 / 认知模型 | 键值库、图数据库、Profile | 长期持久化 | 用户画像、核心偏好、结构化属性 | 用户手动更新、版本合并与冲突覆盖 |
