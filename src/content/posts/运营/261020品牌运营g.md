# 一、 业务背景与运营定位

> 明确行业特性、产品壁垒与合规边界，为内容聚合与发布提供底层导向。

- **品类认知痛点**：宠物干细胞在大众认知中属于新兴/前沿医疗方案，认知门槛高且普遍存在顾虑，必须依托扎实的临床研究与循证依据来建立信任。
- **核心定位（方法论）**：明确“我的行业、我的产品、我的近期目标”，以专业权威破局，以真实案例打动用户。
- **合规性底线**：部分产品属于医疗类目，必须严格基于官方标准审核内容，建立敏感词过滤与合规审批机制。

# 三、 智能中台（数据提炼与决策层）

> 基于聚合的多源数据，借助 AI/RAG 技术提炼高价值选题，过滤噪音，指导选品与宣推。

- **知识库与 RAG 整合**：基于学术源与临床文献提炼高价值核心内容，用于选题与选品建议，所有生成内容必须注明信息来源依据。
- **水军识别与噪音过滤**：识别社交平台主题（帖子/视频）及各级评论的疑似水军概率，确保舆情分析与用户痛点的真实性。
- **热点抓取与爆款分析（FAQ 回应）**：
  - **如何提炼有用内容、提高爆款概率？** 结合实时热点、高点赞、高浏览主题进行回复量与互动分析，识别真实高共鸣议题，提炼用户高频关切的问题点作为选题母本。

# 四、 账号体系与内容矩阵（发布与触达层）

> 搭建国内外多平台矩阵，按账号人设差异化分发，实现专业背书与产品转化的协同。

## 1. 账号矩阵与人设定位
- **主体账号（官方品牌）**：
  - **定位**：官方品牌背书、核心产品合规推广。
  - **运作机制**：AI 托管发布 + 严格流程审批（人工介入审核）。
- **矩阵账号（专业背书与信任扩散）**：
  - **发布阵地**：国内以公众号、小红书为主；海外以 X（已支持自动化发布）、Reddit 为主。
  - **三维人设划分**：
    - **专家/研发人设**：输出学术前沿、科研进展与权威背书。
    - **临床医生/合作医院视角**：分享诊疗科普、临床病例观察与诊疗方案。
    - **宠主故事/救助视角**：分享真实成功案例、康复全过程与情感共鸣。

## 2. 内容生产工作流
- **素材与资产管理**：基于 **Emulsion** 资产中枢，进行 AI 生图、改图、AI 视频/数字人制作。
- **科普/软文内容加工**：
  - 主要推广阵地：知乎、小红书、微信公众号。
  - 生产流程：对接企业医疗知识库，移除关键敏感违规词汇，将专业医学名词通俗化，生成符合大众接受度的科普读物。
- **多形式发布**：支持图文文章、AI 视频/数字人播报。

# 五、 投流加速与数据复盘（增长层）

> 建立“发布-监控-投流-复盘”的正向增长循环，放大优质内容商业价值。

## 1. 全域数据监控与复盘
- **复盘指标**：内容审计、曝光与互动表现、最佳发布时间窗口探索、方案持续迭代。
- **数据分析平台规划**：打通多渠道发布数据回流接口，持续优化选题转化率。

## 2. 精细化商业投流
- **投流平台**：
  - **小红书**：聚光平台、薯条加热
  - **微信生态**：朋友圈广告、公众号广告、微信小程序广告
  - **抖音生态**：千川、巨量投流
  - **海外渠道**：Meta Ads、Google Ads
- **系统能力**：预算自动控制、交易与投放数据追踪、各平台投放 API 深度对接。

# 六、 生态联动与落地实现（协同与落地）

## 1. 外部生态合作
- **医疗端深度协同**：结合宠物细胞产品医疗属性，联合线下相关宠物医院做深度推广、脱敏病例共创与联合内容发布。
- **同域自媒体联动**：与垂直领域优质自媒体、KOL/KOC 合作联合发布，扩大信任背书。

## 2. 系统技术实现链路
- **全链路流转**：从各独立数据源抓取监听 $\to$ 智能清洗过滤与精选 $\to$ 提示词润色 $\to$ 调用 **Workbuddy** 执行内容自动化生成 $\to$ 自动化推送到各平台。
