## 能力层：不统一的部分

四类 agent 后端在同一条产品链路上的能力差异对比。

| 能力                       | Built-in (MOAgent)                                                                            | DSH                                                                                | 外部 CLI                               | Mastra                             |
| ------------------------ | --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------ | ---------------------------------- |
| **工具来源**                 | `@mo-gallery/ai-agent` 运行时 + 前端组装（`editor-ai-local.ts:709` `buildDesktopAgentExtensionTools`） | DSH 自带工具链 + profile bundles（`ai.DSHProfileBundles`，`agent_runtime_service.go:290`） | CLI 自带工具链                            | sidecar 自带工具（Mastra）               |
| **Skills**               | ✅ 渐进披露 + `read_agent_skill` 工具（`editor-ai-local.ts:726`）                                      | ❌                                                                                  | ❌                                    | ❌                                  |
| **用户 MCP server**        | ✅ 前端直连注入                                                                                      | ❌（`streamDSH` 不传 `MCPServers`）                                                     | ✅ 按 CLI 翻译配置（`external_mcp.go:36`）   | ✅ 写进 `RunRequest`（`mastra.go:105`） |
| **场景 MCP（zine/desktop）** | ✅                                                                                             | ❌                                                                                  | ✅ 每场景一份（`externalMCPServers:751`）    | ✅ 同一份                              |
| **权限升级**                 | 前端审批栏，无 runtime 通道                                                                            | DSH 自己的 permission 协议（`RespondPermission`）                                         | CLI 自己的权限模式                          | ❌ 恒失败（`mastra.go:290`）             |
| **图片**                   | 直接进消息                                                                                         | 落盘 workspace                                                                       | 落盘 workspace（`StageAgentImages:324`） | base64 进 stdin（`mastra.go:84`）     |

### 差异集中在三处

1. **扩展机制**：Skills 仅 Built-in 支持；用户 MCP 仅 DSH 缺失；场景 MCP 仅 DSH 缺失。
2. **权限模型**：Built-in 走前端审批栏（无 runtime 通道），DSH/CLI 各有自己的协议，Mastra 完全不通（恒失败）。
3. **多模态输入**：Built-in 直接进消息，DSH/CLI 统一落盘 workspace，Mastra 走 base64 塞 stdin。
