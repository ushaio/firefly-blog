# 若依微服务之 Nacos

## 一、Nacos 是什么

Nacos（**Na**ming and **Co**nfiguration **S**ervice）是阿里开源的一个组件，同时干两件事：

| 能力       | 作用                                    | 在若依里体现在哪                                                                                             |
| -------- | ------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **注册中心** | 服务启动后把自己注册到 Nacos，别人按"服务名"找它，不用写死 IP  | 网关 `ruoyi-gateway` 的 `routes` 里写的是 `lb://ruoyi-system`，靠 Nacos 解析成真实实例                               |
| **配置中心** | 配置文件放在 Nacos 服务端，客户端启动时按 `dataId` 拉下来 | 各服务的 `bootstrap.yml` 里只留 `server-addr`、`namespace`，真正的数据库/Redis 配置放在 Nacos 的 `application-dev.yml` 里 |

一句话：**Nacos = 微服务的"通讯录 + 公共配置柜"**。若依微服务版把它当成基础设施，没有它，网关路由、配置加载都跑不起来。

端口：`8848` 是控制台/HTTP，`9848`、`9849` 是 2.x 的 gRPC 端口（客户端连的是 9848，防火墙要一起放行；只开 8848 会一直报连接超时）。

## 二、如何启动 Nacos

### 1. 准备环境

- JDK 1.8+（若依用的 Spring Boot 2.7 系列，配 JDK 8 或 11 都行）
- MySQL 5.7+（Nacos 1.4 之后可以不用内置 Derby，改用 MySQL 存配置，若依就是这么配的）

### 2. 下载解压

下载 `nacos-server-x.x.x.zip`，解压到没有中文、没有空格的路径，例如 `D:\nacos`。

### 3. 建库 + 导入 SQL

在 MySQL 里建一个库（若依的脚本默认叫 `ry-config`）：

```sql
CREATE DATABASE `ry-config` DEFAULT CHARACTER SET utf8mb4;
```

然后把若依工程里的 Nacos 初始化脚本导入这个库：

```
RuoYi-Cloud/sql/ry_config_20241225.sql     -- Nacos 的配置数据（表结构 + 若依所有的 dataId 配置）
RuoYi-Cloud/sql/ry_cloud_20241225.sql      -- 业务库（建在另一个库，如 ry-cloud）
```

> 注意区分两个库：`ry-config` 只放 Nacos 的配置数据，给 Nacos 自己用；`ry-cloud`（或自定名）才是若依业务表。`ry_config` 脚本里的配置内容还写着 `127.0.0.1:3306/ry-cloud`，业务库名跟它不一致时要去 Nacos 控制台改。

### 4. 改 `conf/application.properties`（这是启动前唯一必须改的文件）

```properties
# 换成 MySQL
spring.datasource.platform=mysql

db.num=1
db.url.0=jdbc:mysql://127.0.0.1:3306/ry-config?characterEncoding=utf8&connectTimeout=1000&socketTimeout=3000&autoReconnect=true&useUnicode=true&useSSL=false&serverTimezone=UTC
db.user.0=root
db.password.0=你的密码
```

（旧版本可能是 `spring.datasource.platform`，2.2 之后改为 `spring.sql.init.platform`，看你下载的版本对照注释改，别照抄。）

### 5. 单机启动

```bash
# Windows
startup.cmd -m standalone

# Linux / Mac
sh startup.sh -m standalone
```

**一定要带 `-m standalone`**，否则默认按集群模式启动，会因为找不到 `cluster.conf` 起不来。

访问 `http://localhost:8848/nacos`，默认账号密码 `nacos / nacos`。

## 三、需要改哪些文件

### A. Nacos 服务端（改本地文件）

| 文件 | 改什么 |
| --- | --- |
| `conf/application.properties` | 数据源：`spring.datasource.platform=mysql`、`db.num`、`db.url.0`、`db.user.0`、`db.password.0` |
| `conf/cluster.conf` | 只有集群模式才需要，写好各节点 `ip:8848`；单机不用 |

改了库里的配置之后，还可以在 `conf/` 下清缓存重启，或者直接用控制台改，改完点「发布」立即生效。

### B. 若依工程端（改项目文件）

| 文件 | 改什么 |
| --- | --- |
| `ruoyi-gateway/src/main/resources/bootstrap.yml` | `spring.cloud.nacos.discovery.server-addr`、`namespace`、`file-extension: yml`、`shared-configs`（公共配置 `application-dev.yml`） |
| `ruoyi-modules/ruoyi-system/.../bootstrap.yml` | 同上，每个微服务的 `bootstrap.yml` 都有一份，`server-addr` 指向你的 Nacos |
| `ruoyi-auth/.../bootstrap.yml` | 同上 |
| `ruoyi-visual/ruoyi-monitor/.../bootstrap.yml` | 同上（可选模块） |
| Nacos 控制台里的 `application-dev.yml` | **不是文件**，是配置内容：MySQL 连接、Redis 连接（`spring.redis.host/password`）、日志级别，全局生效 |
| Nacos 控制台里的 `ruoyi-xxx-dev.yml` | 各服务自己的配置，比如 `ruoyi-gateway-dev.yml` 里的路由，`ruoyi-system-dev.yml` 里的端口 |

`bootstrap.yml` 典型内容：

```yaml
spring:
  application:
    name: ruoyi-system
  profiles:
    active: dev
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848
      config:
        server-addr: 127.0.0.1:8848
        file-extension: yml
        shared-configs:
          - application-${spring.profiles.active}.${spring.cloud.nacos.config.file-extension}
```

> `server-addr` 只在一处改的话，建议用 `nacos` 的 `namespace` 隔离开发/测试环境，而不是改 IP。

## 四、启动顺序

1. MySQL（业务库 + `ry-config`）
2. Redis（若依用 Redis 存 token、验证码）
3. **Nacos**（`standalone`）
4. `ruoyi-gateway`（网关，8080）
5. `ruoyi-auth`（认证，9200）
6. `ruoyi-modules-system`（系统模块，9201）
7. 其他模块（gen、job、file）按需
8. `ruoyi-ui` 前端（`npm run dev`）

验证：Nacos 控制台「服务管理 → 服务列表」能看到 `ruoyi-gateway`、`ruoyi-auth`、`ruoyi-system` 且实例数为 1；「配置管理」里能看到各 dataId。

## 五、常见坑

- **启动报 `No DataSource set`**：`application.properties` 里的 `spring.datasource.platform` 没生效或写错（2.2+ 是 `spring.sql.init.platform`）。
- **报 `failed to req API:/nacos/v1/ns/instance`**：只开了 8848，9848 没开 / 客户端与服务端版本差太多（2.x 客户端连 1.x 服务端会有兼容问题）。
- **服务注册上了但网关 404**：`ruoyi-gateway-dev.yml` 里的路由 `uri` 写的是 `lb://服务名`，服务名必须和 `spring.application.name` 完全一致。
- **配置改了不生效**：检查 `bootstrap.yml` 里有没有把 `spring.cloud.bootstrap.enabled=true`（或用 `spring.config.import`），以及 Nacos 里改的 dataId 后缀 `-dev.yml` 和 `profiles.active` 是否对得上。
- **Windows 启动闪退**：`startup.cmd` 要加 `-m standalone`，并且路径不能有中文空格。
